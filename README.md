# Mini NPU Simulator (MAC 연산 시뮬레이터)

Python을 활용하여 입력 패턴과 필터의 유사도를 MAC(Multiply-Accumulate) 연산으로 계산하고, 결과를 비교하여 패턴을 판별하는 콘솔 프로그램입니다. 행렬 크기에 따른 연산 횟수와 처리 시간을 비교하면서 NPU의 기본 연산 원리를 학습하는 것을 목적으로 합니다.

---

## 1. 실행 방법

### 개발 환경
- 개발 언어: Python 3.10 이상
- 사용 라이브러리: `json`, `math`, `re`, `time`, `pathlib`, `dataclasses`, `typing`
- 외부 라이브러리 설치 없이 실행 가능

### 파일 구성

```text
프로젝트 폴더/
├── main.py       # MAC 연산 및 시뮬레이터 실행
├── data.json     # 필터 및 테스트 패턴 데이터
└── README.md     # 프로젝트 설명 및 결과 분석
```

`main_ui.py`를 `main.py`로 변경하고 `data.json`과 같은 폴더에 저장합니다.

### 실행 명령어

```bash
python main.py
```

### 실행 모드

```text
==========================================================
             MINI NPU | MAC SIMULATOR
==========================================================
  실행할 분석 모드를 선택하세요.

  [1] 직접 입력       - 3x3 행렬 연산
  [2] 파일 분석       - data.json 일괄 검사
  [3] 패턴 생성       - N x N Cross / X (보너스)
----------------------------------------------------------
  모드 번호 >
```

| 모드 | 주요 기능 |
| --- | --- |
| 1. 직접 입력 | 3×3 필터 A, B 및 입력 패턴을 직접 입력하고 MAC 점수와 판정 결과 확인 |
| 2. 파일 분석 | JSON 데이터를 불러와 필터 및 패턴 검증, 일괄 판정, 성능 분석 수행 |
| 3. 패턴 생성 | 입력한 크기의 Cross 및 X 패턴을 자동 생성하고 연산 결과와 성능 비교 |

잘못된 모드 번호를 입력하면 안내 메시지를 출력하고 다시 입력받습니다.

## 2. 주요 구현 내용

### 행렬 관리 (`Matrix`)
- N×N 크기의 행렬을 2차원 리스트로 구성하고 각 데이터를 실수형으로 저장합니다.
- `get()`과 `set()`을 통해 지정한 위치의 값을 조회하거나 변경합니다.
- 행렬의 크기 및 인덱스 범위를 검사합니다.

### MAC 연산 (`compute_mac`)
- 입력 패턴과 필터에서 같은 위치에 있는 값을 곱한 후 모두 더합니다.
- 이중 `for` 반복문을 사용하며, 두 행렬의 크기가 동일한지 확인합니다.
- 계산된 MAC 점수를 비교하여 더 높은 점수를 가진 필터를 선택합니다.

### 라벨 정리 및 판정 (`normalize_label`, `compare_scores`)
- `+`, `cross`는 `Cross`로, `x`는 `X`로 통일하여 비교합니다.
- 실수 계산에서 발생할 수 있는 오차를 고려하여 허용오차를 `1e-9`로 설정했습니다.
- 두 점수의 차이가 허용오차보다 작으면 동점으로 처리합니다. 직접 입력 모드에서는 `판정 불가`, 파일 분석 및 패턴 생성 모드에서는 `UNDECIDED`로 표시합니다.

### 입력값 및 JSON 데이터 검증
- 직접 입력 시 행마다 필요한 숫자의 개수, 숫자 변환 가능 여부 및 유한수 여부를 검사합니다.
- 잘못 입력한 행은 안내 메시지를 표시한 후 다시 입력받습니다.
- JSON 분석 시 필터 존재 여부, 행렬 크기, 데이터 형식 및 기대값 라벨을 확인합니다.
- 개별 패턴의 검증에 실패하면 해당 케이스를 FAIL로 기록하고 다음 패턴의 분석을 진행합니다. 파일 자체를 읽지 못하거나 상위 구조에 오류가 있으면 해당 분석을 종료합니다.

### 성능 측정 (`benchmark_mac`)
- `time.perf_counter()`를 사용하여 MAC 연산 구간을 10회 반복 측정합니다.
- 평균 연산 시간(ms)과 크기별 연산 횟수(N²)를 표로 출력합니다.

### 보너스 기능: 패턴 자동 생성
- `generate_cross_pattern()`은 중앙 행과 열을 1로 채워 Cross 패턴을 생성합니다.
- `generate_x_pattern()`은 두 대각선을 1로 채워 X 패턴을 생성합니다.
- 생성된 행렬 중 하나를 입력 패턴으로 선택하여 MAC 연산을 수행합니다.
- 3×3, 5×5, 13×13, 25×25 및 사용자가 입력한 크기의 성능을 비교합니다.

| 구분 | 예상 MAC 점수 |

| 필터 A | 5.0 |
| 필터 B | 1.0 |

### 3-2. data.json 분석 및 실패 원인

아래 표는 제공된 README 예시의 테스트 결과를 참고한 것입니다. 실제 제출용 데이터 파일과 실행 결과를 확인한 뒤 수치를 확정해야 합니다.

| 케이스 ID | Cross 점수 | X 점수 | 판정 | 기대값 | 결과 |
| --- | ---: | ---: | --- | --- | --- |
| size_5_1 | 0.9 | 0.8999999999999999 | UNDECIDED | X | FAIL |
| size_5_2 | 8.9 | 0.1 | Cross | Cross | PASS |
| size_13_1 | 0.3 | 14.700000000000008 | X | X | PASS |
| size_13_2 | 7.499999999999997 | 7.5 | UNDECIDED | Cross | FAIL |
| size_25_1 | 4.9 | 4.899999999999999 | UNDECIDED | X | FAIL |
| size_25_2 | 52.9 | 0.1 | Cross | Cross | PASS |

참고 결과는 전체 6개 중 PASS 3개, FAIL 3개입니다.

실패한 세 케이스는 두 필터의 점수가 수학적으로 같거나 허용오차 이내로 계산된 경우입니다. 예시 데이터에서는 5×5의 0.1 × 9 = 0.9, 13×13의 0.3 × 25 = 7.5, 25×25의 0.1 × 49 = 4.9가 각각 상대 필터의 점수와 같습니다. 실수 표현에 따른 미세한 차이를 근거로 특정 필터를 선택하지 않도록 동점 처리 규칙을 적용했으며, 기대값과 일치하지 않는 UNDECIDED 결과는 FAIL로 분류됩니다.

### 3-3. 크기별 성능 및 시간 복잡도

| 행렬 크기 | MAC 연산 횟수 | 평균 시간(ms) |
| --- | ---: | ---: |
| 3×3 | 9 | 측정 후 기입 |
| 5×5 | 25 | 측정 후 기입 |
| 13×13 | 169 | 측정 후 기입 |
| 25×25 | 625 | 측정 후 기입 |

MAC 연산은 행과 열을 각각 N번 반복하므로 총 N²회의 위치별 곱셈 및 누적 덧셈을 수행합니다. 따라서 시간 복잡도는 O(N²)입니다. 행렬의 크기가 증가하면 연산량도 증가하며, 실제 처리 시간은 실행 환경 및 측정 시점에 따라 달라질 수 있습니다.

이러한 반복 연산을 병렬로 처리하는 NPU의 필요성을 이해하는 데 활용할 수 있습니다. 본 프로그램은 실제 NPU 하드웨어가 아닌 CPU에서 실행되는 소프트웨어 시뮬레이터입니다.
